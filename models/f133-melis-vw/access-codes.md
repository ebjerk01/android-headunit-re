# Factory / engineering access codes — F133 / MelisOS (this unit)

Typically **Settings → Factory settings → 6-digit code**. **Community** = widely reported for
F133 / Melis units (Navifly, EKIY, generic) incl. manufacturer manuals — **not yet verified on
this specific unit** (no access yet). Harmless to try the wrong one; avoid anything that flashes.

| Code | Opens | Source |
|---|---|---|
| **113266** | **Factory / Advanced settings** (the main one) | Community (mfr manuals, multiple) |
| **000000** | Firmware **Update** screen (also triggers the SD `\Update\` scan) | Community + matches the Melis `update.mod` factory trigger |
| 112233 | Boot logo / startup screen settings | Community |
| 112345 | Debug mode | Community |
| 230762 | Interface / UI selection | Community |
