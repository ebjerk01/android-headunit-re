# Platform: Qualcomm QCM6125 (Snapdragon)

Snapdragon 662-class automotive SoC, **Android 13**, the Microntek/HCT (`android.microntek`)
vendor stack. The modern, more-capable alternative to the MT8127 units. Reference RE used a
Dasaita G13 OTA (closest public QCM6125 Android 13 build).
